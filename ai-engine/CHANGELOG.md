# Nara AI-Engine Changelog & System Overview 📝

This file serves as the collaborative single source of truth for the **Nara Nutrition AI-Engine**. It documents all major architectural shifts, data pipeline updates, and system decisions to keep all team members (Data, Frontend, and AI) fully aligned.

---

## [1.1.0] — 2026-06-01
This update introduces a major shift from statistical regression (KNN) to a high-precision, biologically constrained **Rules-Based Expert Imputation System**, alongside a **Modular Data Pipeline Reorganization**.

### 🌟 Key Highlights & Why They Matter
1. **From KNN to Expert Rules**: The statistical KNN model previously matched foods strictly by numerical macronutrient values, lumping unrelated items (e.g. predicting spinach has cholesterol or underestimating dried bony fish calcium by 800%). We replaced this with an expert system that classifies food via word-boundary parsing and applies precise nutritional overrides.
2. **Modular File Restructuring**: Relocated 20+ flat files from the root of `ai-engine/` into dedicated pipeline stages (ingestion, preprocessing, imputation, parsing, analysis) under `src/` and `docs/` to follow enterprise-grade repository standards.
3. **The `main.py` CLI Entrypoint**: Rather than running disparate scripts in isolation, a central orchestrator script in the root is used. It keeps the current working directory as the root, meaning no relative paths are broken!
4. **Preserved Compatibility**: Kept `datasets/master/` in the same base location to prevent breaking any frontend Next.js APIs or client-side fetches expecting master databases there.

### 🧪 Scientific Imputation Rules & Safety Clips
Our expert system implements rigorous physical constraints during row-by-row imputation of **1,346 Indonesian food items**:

1. **Dried & Salted Fish**: Categorized via word boundaries (e.g. `teri`, `asin`, `kering`, `gereh`, `peda`). Receives high Calcium ($850\text{ mg}$), high Iron ($4.5\text{ mg}$), and high Sodium ($1.5\text{ g}$) to match physical dried bones and curing.
2. **Tempeh & Fermented Soy**: Granted $1.2\text{ mcg}$ of active fermentation `Vitamin B12`, while other plant foods are strictly set to $0.0\text{ mcg}$.
3. **Tofu (Tahu)**: Set to $220\text{ mg}$ of Calcium to represent calcium-sulfate coagulation.
4. **Organ Meats**: Adjusted for organ density (e.g. Liver receives $18\text{ mg}$ Vitamin A and $28\text{ mcg}$ Vitamin B12; Kidney receives $9\text{ mg}$ Vitamin C).
5. **Plant Cholesterol Block**: Cholesterol is strictly forced to **$0.0\text{ mg}$** for all plant-based items.
6. **Fat Breakdown Bound**: Saturated + Monounsaturated + Polyunsaturated Fats are scaled proportionally so their sum does not exceed total Fat.
7. **Water Balance**: Water is calculated dynamically as:
   $$\text{Water} = 100 - (\text{Protein} + \text{Fat} + \text{Carbohydrates} + \text{Ash}) \quad [\text{clipped strictly between } 0\text{g and } 95\text{g}]$$
8. **Recalculated Nutrition Density**: Computed using your exact beneficial formula:
   $$\text{Density} = \frac{\text{P}\times4 + \text{Fiber}\times3 + \text{VitC}\times0.5 + \text{VitA}\times0.01 + \text{Iron}\times5 + \text{Calcium}\times0.1 + \text{Potassium}\times0.05 + \text{Mag}\times0.2 + \text{B12}\times20 + \text{Zinc}\times3}{\max(\text{Caloric Value}, 1)}$$

### 💻 Collaboration & Commands
The pipeline is run from the root of `ai-engine/` using a single executable:

* **Trigger the end-to-end production data pipeline** (Ingestion ➜ Preprocessing ➜ Expert Imputation ➜ Quality Audit):
  ```bash
  python main.py --all
  ```
* **Run ONLY the Expert Rules Imputation**:
  ```bash
  python main.py --impute
  ```
* **Run ONLY the Quality Exploratory Data Analysis (EDA)**:
  ```bash
  python main.py --eda
  ```
* **Add new package modules**: Place scripts inside the respective subdirectory under `src/` and import them cleanly. Always use `main.py` in the root as your execution context to avoid path shifts.
